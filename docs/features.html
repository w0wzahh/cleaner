Full feature list

Everything a cleaner should do

Seven focused tools, a scheduling engine, a tray mode, and a CLI for scripting — wrapped in an interface that animates instead of snapping.

Cleaning tools

Find the junk, wherever it hides

Custom Clean

Point it at any folder and filter by extension, glob pattern, age, or size. Recursive and hidden-file toggles included. Full preview before anything is touched.

Duplicate Finder

Groups files by size, fingerprints with xxh3 (first 8 KB + last 4 KB + size), and only runs a full BLAKE3 hash when it has to — all in parallel across every CPU core. A 12,000-file folder with 6,000 duplicate groups scans in well under a second.

System Cleaner

Temp folders, app caches, browser caches (Chrome, Edge, Firefox), and the Windows thumbnail cache. Pick which targets are in scope — and add your own.

Large File Finder

Everything above a size you pick, sorted biggest first, with one-click reveal in Explorer so you can eyeball it before deciding.

Empty Folder Cleaner

Finds empty directories — including ones that only become empty once their children are removed.

Folder Sizes & Storage Overview

Ranks a folder's subfolders by total size, plus per-drive usage bars so you can see exactly where the space went.

Workflow

Set it, forget it, script it

Scheduled Scans

Run a scan every hour, 6/12/24 hours, or weekly while the app is open — with optional auto-clean afterwards. Can also register a Windows Task Scheduler entry so scans run even when the app is closed.

System Tray Mode

“To tray” hides the window while Cleaner keeps running its schedule in the background. Double-click the icon to bring it back.

Full Command Line

cleaner scan-custom <dir>, cleaner clean-system --yes and friends, for scripting or Task Scheduler. See the CLI reference.

Sortable Results & Reports

Order results by size or name on the Custom Clean, Duplicates, and Large Files tabs, and export a report of any scan to keep for your records.

Six Animated Themes

Midnight, Dark, Light, Nord, Dracula, and Solarized — and switching between them animates instead of snapping.

Zero Network Calls

No telemetry, no analytics, no accounts, no update pings. Cleaner literally never opens a socket — verify it yourself, the source is on GitHub.

Safety

Destructive, only when you mean it

Dry run & recycle bin by default

Out of the box, scans only preview matches and deletion goes to the recycle bin. Permanent delete and secure erase are strictly opt-in, and every clean asks for confirmation first.

Protected paths & history log

A protected-paths list that's never scanned or deleted, optional 3-pass secure erase for files you really want gone, and a persistent log that records every operation.
