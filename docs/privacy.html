01Data collection by the application#

Cleaner makes zero network calls. It contains no telemetry, no analytics, no crash reporters, no advertising identifiers, and no accounts. The application does not collect, transmit, store remotely, or share any personal data — it can't, because it never opens a network connection.

You don't have to take our word for it: the entire source code is published at github.com/w0wzahh/cleaner and can be audited by anyone, at any time.

02Data stored locally#

Cleaner stores a small number of files on your own machine so it can do its job:

  • cleaner_settings.json — your preferences (theme, filters, protected paths).
  • cleaner_history.log — a persistent record of every scan and clean operation.
  • reports\ — scan reports you choose to export.

These files live next to the executable (or in %APPDATA%\Cleaner\ when that folder is read-only). They never leave your device and are only read or written by Cleaner itself. Uninstalling and choosing "delete the data folder" removes them completely.

03This website#

This website is a set of static pages. It sets no cookies, runs no analytics, loads no third-party trackers or fonts, and collects no information about you.

The only optional request it makes: the download buttons may query GitHub's public Releases API (api.github.com) once, read-only and unauthenticated, to keep the links pointed at the newest release. Nothing is sent beyond the request itself, and if it fails the buttons fall back to a pinned release URL.

04Third-party services#

Links on this site point to services operated by third parties with their own privacy policies:

  • GitHub (github.com) — source hosting, releases, and issue tracking.
  • Ko-fi (ko-fi.com) — optional donations.

If you visit those services, their own policies apply. Cleaner and this website receive no data back from them.

05Children's privacy#

Because Cleaner collects no data from anyone, it inherently collects no data from children.

06Changes to this policy#

If this policy ever changes, the updated version will be posted on this page and in the repository. Given the app's zero-network design, we don't expect it to change much.

07Contact#

Questions about this policy? Open an issue on GitHub.
