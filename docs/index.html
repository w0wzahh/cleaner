The toolkit

Find the junk, wherever it hides

Seven focused tools — no bundled nonsense, no "registry optimizer" scare tactics. Each one previews before it touches a byte.

Custom Clean

Point it at any folder and filter by extension, glob pattern, age, or size. Recursive and hidden-file toggles included.

Duplicate Finder

xxh3 fingerprints first, full BLAKE3 only when it has to — parallel across every CPU core.

System Cleaner

Temp folders, app caches, browser caches, and the thumbnail cache. Pick your targets — or add your own.

Large File Finder

Everything above a size you pick, sorted biggest first, with one-click reveal in Explorer.

Empty Folder Cleaner

Finds empty directories — including ones that only become empty once their children are removed.

Storage Overview

Ranks a folder's subfolders by total size, plus per-drive usage bars so you see where the space went.

Safety model

A deletion tool you can trust

Cleaner deletes files — so every default is tuned to make the destructive path the deliberate one.

dry_run

On out of the box. Nothing is deleted until you turn it off.

use_trash

Deletions go to the recycle bin by default; permanent delete is opt-in.

confirm_clean

Every clean asks for confirmation first — even from the CLI.

secure_delete

Optional 3-pass overwrite for files you really want gone.

protected_paths

A list that's never scanned or deleted. Period.

history log

A persistent log records every scan and clean operation.
